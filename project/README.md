# 🪐 Orbitly: AI-Powered Customer Churn Prediction & Retention Assistant

**Live demo:** <paste your Streamlit link here>

Orbitly predicts which telecom customers are likely to leave, explains why, groups them into
behavioural segments, and suggests a retention offer. It can also train a quick model on your
own churn CSV.

![Orbitly screenshot](screenshots/home.png)

## Features
- **Single customer prediction:** churn risk score, segment, and the top factors pushing risk up or down
- **Retention assistant:** an LLM (via Groq) explains the segment and picks offers from an approved menu
- **Batch scoring:** upload a telecom-format CSV, get every customer scored and downloadable
- **Bring your own data:** upload any customer CSV with a churn column; Orbitly trains a model,
  reports ROC-AUC / recall / precision, flags suspiciously strong (possibly leaky) columns, and scores everyone

## Tech stack
Python, Streamlit, scikit-learn (Logistic Regression, K-Means), pandas, Groq API

## Run locally
```bash
git clone <your repo url>
cd <repo folder>
pip install -r requirements.txt
# create a .env file containing: GROQ_API_KEY=your_key_here
streamlit run app.py
```

## Data and limitations
- The telecom model was trained on the public Telco Customer Churn dataset (prices in US dollars).
- Results are a demonstration, not business advice. Risk scores are relative, not exact probabilities.
- The segment explanations and retention offers are generated by an LLM and should be reviewed by a person.
- In "Bring your own data", scores come from cross-validation; patterns shown are associations, not proven causes.

## Project files
- `app.py`: the Streamlit app
- `*.pkl`: trained model files from the Colab notebook
- `requirements.txt`: dependencies (pin `scikit-learn` to the version used for training)
